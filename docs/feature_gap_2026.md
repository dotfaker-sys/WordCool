# 单词酷 · 市面背单词产品功能差距（2026-11）

> 说明：无法穷举“所有”产品；本文抽样了 6 款国内主流（墨墨、扇贝、百词斩、不背单词、知米、欧路）和 5 款国外/通用（Anki、Quizlet、Memrise、Drops、Clozemaster/Lingvist 类）产品，按公开商店说明、官网与评测文章核对。价格和功能会变，以各产品当前页面为准。

## 1. 结论先行

单词酷已经有的：离线词库、Unit/Day 导入、UK/US 音标、双 TTS、间隔复习、自评、4 选 1、拼写测试、多选范围、顺序/打乱、Group 折叠、行内发音、统计、JSON 备份、内置考研词库。

和主流产品相比，最明显的缺口不是“会不会背”，而是**词条内容厚度、练习题型、计划与提醒、单词级数据**这四块。

## 3. 最值得补的 5 件事

1. **词条内容层**：给词条补 `例句 / 真题例句 / 词根词缀 / 近反义 / 搭配 / 词形`。没有内容，练习题型和复习算法都只能空转。
2. **考试计划与提醒**：考试日期倒计时、每天新词/复习拆分、到点通知；通知需要 `POST_NOTIFICATIONS`，与当前“仅 INTERNET”口径冲突，建议做成默认关的开关。
3. **练习题型扩展**：听音选义、听写、中译英、例句填空。现有 `meaning`/`example`/TTS 已经能支撑前三种，不必引入新数据源。
4. **单词级数据**：每个词的答题历史、熟悉度、错误次数、下次复习、掌握曲线；现在只有总数和正确率。
5. **可视化与无障碍**：深色模式、字号/行高设置、长词完整显示（已做）、列表折叠（已做）。

## 4. 不建议照抄的

- 开屏广告、信息流、电商、课程推销：与“离线、干净”的定位冲突。
- 强制账号、云端同步：会打破当前“本地词库、不上传”的承诺；可以做成可选导出。
- 社交组队/PK：需要账号与联网，投入大，对单人备考收益有限。
- AI 生成例句/作文批改：需要联网与大模型成本，和“唯一联网点是检查更新”不一致；可作为未来可选模块。
