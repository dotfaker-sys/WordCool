# 单词酷 · Android 单词本

一个**以离线为主**的安卓单词本（唯一联网点是「检查更新」，见 v9）：管理自己的词库、按「解锁 → 学习 → 已掌握」把单词真正学会，还能把 **Word / Excel / 文字型 PDF** 里的单词表导进来并自动划成 Unit / Day 小组，卡片上**英音 / 美音都能点、UK / US 双音标并排显示**。

> **v9 · 应用内检查更新（当前 v1.2 / versionCode 3）**：「统计」页底部新增「版本与更新」，显示当前版本，点「检查更新」读取一次 GitHub 公开 Release 版本号，发现新版弹窗并跳转下载页；也能打开「启动时自动检查」，之后只有真有新版才弹窗。**这是全应用唯一会联网的地方，也是相对前几版唯一新增的权限（`INTERNET`）**：只在用户点按钮或自己开开关时发一次只读 GET，不上传词库、账号、设备信息，**不自动下载、不自动安装** APK。词库、导入、离线音标词典、双发音、复习、备份**全部仍离线可用**，没网也能背单词；不想要就别开开关。详见 [`DESIGN.md`](DESIGN.md) 第 11 节。
>
> **v8 · 从微信 / QQ 直接导入**：微信里点开词表 → 右上角「…」→「用其他应用打开」，或长按文件「分享」→ 选「单词酷」，文件直接进导入预览，**不用先存到手机**。三种系统入口都接了（`ACTION_VIEW` / `ACTION_SEND` / `ACTION_SEND_MULTIPLE`），支持多选文件合并成一批预览、把一段词表文字直接分享进来；QQ / 企业微信 / 文件管理器同一套入口。导入页新增「⑦ 从微信 / QQ 导入」操作指引与排障。**不读微信私有目录**：只有你主动在微信里选了本应用，系统才把那一个文件的临时读取权交给它；导入本身不需要联网。详见 [`DESIGN.md`](DESIGN.md) 第 10 节。
>
> 版本 **v1.2（versionCode 3）**。GitHub Actions 曾**真实编译出 APK 并自动发布 Release**（见 <https://github.com/dotfaker-sys/WordCool/releases>），但该工作流现已按用户要求移除，push 不再自动出包。仍未做的是真机点按测试。
>
> **v7 · 先查别人怎么做，再改代码**：对照欧路、词藤、List、Anki、Quizlet 与 6 类开源数据源做了一轮实证调研（全文见 `docs/research_competitors_ipa.md`），据此修了 5 个短板：① 音标补全从「三列全空才补」改成**逐字段只补空**（文档给了单音标也能补出 UK/US 两列）；② 加 36 组**英美拼写别名**（color↔colour、center↔centre…）；③ 同形异读**保留全部候选**，不再只取第一条；④ 导入预览列出**未命中词清单**并可一键复制；⑤ 数据附**上游 SHA-256** 可复核。用 9,894 个高频词实测：**94.9% 能查到音标，77.6% 英美双套齐全，5.1% 查不到**（多为缩写，留空不编造）。详见 [`DESIGN.md`](DESIGN.md) 第 9 节。
>
> **v6 · Word 里只有单词和汉语意思也能补全音标**：随包内置一份**离线开源音标词典**（v7 重建后 146,647 条，英 / 美两套），导入时自动查表补上 UK / US 音标，卡片不再空着。**查表不需要联网、不装别的 App、不要账号**，只是 APK 多约 4.4 MB。只补空字段，文档里写了音标的、你手填的都不会被覆盖；词组、生造词、词典没收录的词仍留空，不会编造。可在「导入 → ⑥ 音标自动补全」关掉或给老词库批量补一次。数据许可见 `LICENSES/THIRD_PARTY_NOTICES.md`，详见 [`DESIGN.md`](DESIGN.md) 第 8 节。
>
> 这一版还补了：朗读失败会给出具体原因（不再点了没声不知道为啥）、语速三档、一键试听、以及随包自检脚本 `tools/verify.py`（`python3 tools/verify.py`）。
>
> **v5 双发音 + 双音标**：学习卡片并列「英音 UK」「美音 US」两个按钮，点哪边用哪边口音读；文档里写 `UK /…/ US /…/` 会自动拆成两套音标，词条里也能手动补。发音走系统 TTS 的**本地离线语音包**，会检查语音包是否真的可用、缺包自动回退并引导安装。当时写的「离线应用没有内置词典、不会凭空生成音标」这句，**v6 起已被随包内置的离线开源音标词典取代**（仍然不凭空编造，只是改成查真实词典）；音色由手机装的 TTS 语音包决定。详见 [`DESIGN.md`](DESIGN.md) 第 7、8、9 节。
>
> **v4 缺陷修复**：对全部源码做了一轮逐行走查，修掉 15 个可确证问题（按组解锁、队列缓存、卡片/小测被跳过、词性单空格吞中文、CSV 引号、表头误收词、标题行混排、`sheet2.xml`、PDF 按 `/Length` 截流、组别自然排序等），完整清单见 [`DESIGN.md`](DESIGN.md) 第 6 节。此后 GitHub Actions 曾**真实编译通过并产出 APK**（该工作流现已移除），但**仍未做真机点按测试**，不能承诺运行时零缺陷；遇到具体报错请把截图或错误文字发来。
>
> **v3 功能扩展**：学习页一次只看一个单词、自己点「下一个」；导入支持多格式，文档里的 `Unit 1` / `Day 2` / `第 3 单元` 标题行自动划组，导入后还能改名、按顺序自动划组、按组筛选与学习。全部旧接口只增不减，详见 [`DESIGN.md`](DESIGN.md) 第 5 节。
>
> **v2 视觉重设计**：界面为「墨卡 / INK CARD」设计系统（纸感米白 + 墨黑 + 朱红、英文衬线体、1px 细线、微圆角）。设计 token、WCAG 2.2 对比度校验、安卓分层建议与接口冻结清单见 [`DESIGN.md`](DESIGN.md)；分层架构图见 [`docs/architecture.html`](docs/architecture.html)。

- **零第三方依赖**：只用 Android 官方 SDK（SQLite / XML 解析 / 系统文件选择器 / 系统 TTS），不引 AndroidX、不引网络库
- **权限最小化**：v1.0/v1.1 为零权限；**v1.2 起仅新增 `INTERNET` 一个权限**，只给「检查更新」用，其余仍不申请存储、定位、通讯录等任何权限。词库只存在手机本地，所有背单词功能离线可用
- 支持 Android 8.0（API 26）及以上，Kotlin + Gradle 8.2 + AGP 8.1.4
- 源码仓库里不放 APK；**现成安装包在 [Releases](https://github.com/dotfaker-sys/WordCool/releases)**，也可按下面任一方式自行编译

## 一、怎么拿到可安装的 APK

### 方式 0：直接下载（最快）

打开 <https://github.com/dotfaker-sys/WordCool/releases> → 最新一条 → **Assets → `WordCool.apk`** → 传到手机安装。这是移除工作流之前由 GitHub Actions 真编译出来的 Debug 签名包，可直接安装；工作流移除后不会再自动产生新包。

### 方式 A：电脑 + Android Studio（最省事）

1. 把本仓库 clone 到本地（或下载 ZIP 解压），安装 [Android Studio](https://developer.android.com/studio)
2. `File → Open` 选择 `WordCool` 目录，等 Gradle 同步完成（首次需联网下载依赖）
3. 二选一：
   - 手机打开「USB 调试」连上电脑，直接点 ▶ **Run**，自动装到手机
   - 菜单 `Build → Build APK(s) → Build APK(s)`，产物在
     `app/build/outputs/apk/debug/app-debug.apk`，传到手机上点一下安装

### 方式 B：GitHub 云编译 —— 已移除

仓库里的 `.github/workflows/build-apk.yml` 已按用户要求删除，**push 到 `main` 不会再自动编译、也不会自动发新版 Release**。已有三条 Release（v1.0.0 / v1.1.0 / v1.2.0）和它们的 APK 都保留，仍可从方式 0 直接下载。

以后要出新包，走方式 A（Android Studio）或方式 C（命令行）本地编译；想恢复自动发版，把工作流文件加回 `.github/workflows/` 即可。`UPLOAD.md` 只讲怎么推源码，不再涉及 Actions。

### 方式 C：命令行

需要 JDK 17 + Android SDK（platform 34、build-tools 34.0.0）：

```bash
gradle wrapper --gradle-version 8.2
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> Debug 包已用自动生成的 debug 证书签名，可以直接安装自用。若要正式发布，请在 `app/build.gradle` 里换成自己的签名配置。

## 二、功能速览

| 页面 | 能做什么 |
| --- | --- |
| 词库 | 搜索、按状态筛选、**按组筛选**、添加/编辑/删除（含组别、英/美音标）、查看掌握进度与下次复习时间、一键解锁新词 |
| 学习 | **一次一张单词卡、答完自己点「下一个」**、按组学习、**英音 UK / 美音 US 双按钮 + 双音标**、三档自评、4 选 1 小测验、今日进度条 |
| 统计 | 词库总量 / 已解锁 / 已掌握 / 今日已学、解锁进度、答题正确率、连续打卡、近 7 天柱状图、**版本与更新（检查更新 / 启动时自动检查开关）** |
| 导入 | **微信 / QQ 直接分享进来（含多选与文本分享）**、**Word / .xlsx / 文字型 PDF** 导入、**Unit/Day 自动划组**、`UK /…/ US /…/` 双音标识别、**离线词典自动补全音标**、划组管理、**发音设置（默认口音 / 语速 / 试听 / 语音包安装入口）**、粘贴导入、导入预览中统一改组、JSON 备份与恢复、每日新词数、示例词库、清空词库 |

**「解锁」是怎么运作的**

```text
新导入 → 未解锁 → 每天解锁一批 → 学习中
       → 卡片自评 + 小测验 → 连对 3 次 → 已掌握
```

- 答错：连对清零、当天重新出现；答「模糊」：隔 1 天再来
- 答「认识」：按 1 / 2 / 4 / 7 / 15 / 30 天递增复习间隔
- 所有新词默认未解锁，不会一上来就把几百个词糊到你脸上

## 三、导入格式与划组

支持 `.docx`（段落 / 两列表格）、`.xlsx`（两列）、**文字型 `.pdf`**、`.txt` / `.csv`，以及直接粘贴文本。下面这些写法都能识别：

```text
Unit 1
abandon  /əˈbændən/  放弃
after  UK /ˈɑːftə/  US /ˈæftər/  在…之后
benefit - 益处

Day 2
curious：好奇的
take off	起飞
1. illustrate  v. 说明；举例
apple
```

- 每行第一个英文词/词组作为单词，后面的中文作为释义
- 分隔符支持 Tab、两个以上空格、`-` `—` `:` `：` `;` `；` `,`，自动跳过行首序号和常见词性缩写
- `/.../` 或 `[...]` 会自动识别为音标；表格里的长英文例句会单独放进「例句」
- **英 / 美双音标**：`UK /ˈɑːftə/ US /ˈæftər/`、`BrE[…] AmE[…]`、`英式/美式` 标注会拆成两套，卡片上并排显示；只写一个音标时，缺的那一列也会查离线词典补上
- **自动补全音标**：文档里没写音标也没关系，导入时自动查随包内置的离线开源词典（146,647 条，英美分列）。**逐字段只补空**、不覆盖手写内容；支持 color↔colour 等英美拼写别名；同形异读保留全部候选；未命中词在预览里列出、可一键复制，**留空不编造**。9,894 个高频词实测命中 94.9%。数据是严式音素转写（含 `ɫ` `ɝ` `ɐ`），与课本宽式 IPA 略有差异，可在词条里手动改
- **双发音**：卡片上「英音 UK」「美音 US」各一个按钮，分别请求系统 TTS 的 `en-GB` / `en-US` 本地语音包；没装对应口音时自动回退到另一种并提示，导入页「⑤ 发音与音标」可切默认口音、跳到系统语音包安装
- **自动划组**：`Unit 1` / `Day 2` / `Lesson 10` / `第 3 单元` / `第十二课` 这类标题行会归一成 `Unit 1` / `Day 2`，后续词条自动归到该组；标题行本身不会变成单词
- 导入前会弹出**预览**（显示识别到几个词、划成几组），还能点「统一改组」把这一批词设成同一个组
- 已存在的词不会覆盖你改过的释义和学习进度，只补空字段
- 导入后去「导入 → 划组管理」：点任一组改名，或填前缀 + 每组个数按顺序自动划组（前缀填 `Unit 1 Day` 可得到 `Unit 1 Day 1`）；词库页、学习页顶部都能按组筛选

**格式限制**：旧版二进制 `.doc` / `.xls` 请另存为 `.docx` / `.xlsx`；Excel 只读第一张工作表；**扫描图片版 PDF 没有文字层，导不出**，请复制内容用「粘贴导入」；PDF 若用 CID 字体，中文释义可能乱码或缺失，优先用 Word / Excel。

## 五、常见问题

- **装不上 / 提示解析包错误**：确认手机是 Android 8.0 以上；用方式 A 重新 Build 一次
- **点英音 / 美音没声音或口音不对**：系统需要装有英语（英国 / 美国）**本地离线语音包**。到「导入 → ⑤ 发音与音标」看当前状态、点「安装 / 检查英语语音包」；只装了一种口音时，另一种会自动回退并提示。首次启动 TTS 引擎需要几秒
- **卡片上没有音标**：说明这个词没被内置词典收录（词组、自造词、极生僻词常见）。可在导入页点「给现有词库补一次音标」，或点词条 →「查内置词典补全音标」，也可以自己手填「英式音标 UK」「美式音标 US」。**不会瞎编一个给你**
- **音标看起来跟课本不一样**：内置数据是开源严式音素转写（如 `/ˈæftɝ/`、`/dɪˈɫɪbɝˌeɪt/`），符号更细。保留原样是为了不引入改写错误，习惯课本写法就在词条里改
- **想确认发音到底行不行**：导入页「⑤ 发音与音标」→「试听一句英文」。没声音会给出具体错误码提示（音量 / 输出 / 语音包 / 引擎），按提示处理
- **导入后词不对**：先看导入预览；太长的句子、纯标题行会被自动过滤，必要时在词库里点词条手动改（也能单独改组别）
- **PDF 导不出词**：扫描版没有文字层；或中文字体是 CID 编码，能取到英文词但释义乱码，改用 Word / Excel 或粘贴导入
- **组别不对**：导入页「划组管理」点组改名，或按顺序自动重划；词库页 / 学习页顶部可切换组别
- **换手机**：在旧手机「导入 → 导出词库备份」，把 JSON 传到新手机，用「选择文档并导入」选这个 JSON 即可恢复（含学习进度与组别）
